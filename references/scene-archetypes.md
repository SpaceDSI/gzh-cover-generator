# 右侧主题场景设计语言 / Right-side Thematic Scene System

> 从 5 张标杆公众号封面（信息传送门 / 内容画廊 / 桌面实物 / 自动化飞轮 / 数据流）提炼，
> 并按「不限于参考图、按标题+主旨自主生成」扩展为 9 种场景原型。
> 目标：右侧不再留白或贴轻量小图标，而是产出一张**与文章语义同频的电影级主视觉场景**。

## 0. 为什么改用「场景」而非「矢量图标」

标杆封面的右侧都是**完整的 AI 生成场景**（传送门、卡片群、飞轮、数据流、实物静物），
自带叙事与质感；叠加式小图标（gear/agent 之类）在缩略图里只是噪点。
因此：

- **右侧主视觉由 ImageGen 背景承载**（`scene_concepts.py` 注入主题场景描述）。
- **PIL 矢量图层（`cover_motifs.py`）降级为可选点缀**：默认仍画（低透明度、品牌稳定），
  但追求标杆同款纯场景感时，brief 里设 `"right_motif": "off"` 关闭即可。
- 标题区像素零改动的安全约束不变。

## 1. 构图铁律（所有原型共用）

| 项 | 规则 |
|---|---|
| 画布 | 2.35:1（2350×1000） |
| 左侧 55–62% | **干净负空间**，留给代码渲染的中文标题，场景不得侵入 |
| 右侧 38–45% | **主题场景**，语义驱动，景深/光效/质感拉满 |
| 朋友圈安全区 | 分享只保留**右侧** ~42.6% 方形（2350×1000 → x 1350–2350），正好是主题场景；场景须能独立成图，不侵入左侧标题像素区 |
| 无文字 | 场景内卡片只有**抽象占位文字条/勾选点**，绝无可读中文（防 AI 乱码） |
| 无人物 | 不出现人、脸、头像、背影、剪影（标杆有 1 张出人，但人脸生成高风险，本技能禁止） |
| 无 logo / 水印 | 不出现真实品牌标识 |

> **与标杆的刻意取舍**：标杆卡片带中文小标签（「日报摘要」「选题库」等）。
> 本技能为杜绝 AI 生成中文乱码，把这些标签替换为**抽象占位文字条**，真实文案一律走
> 代码渲染的标题/副标层。场景只负责「氛围 + 物件叙事」，文字只负责「精确不错字」。

## 2. 9 种场景原型

每种原型给出「触发语义」+「深色版」+「浅色版」三件套。色调跟随风格（深色风格用 dark，
浅色风格用 light），由 `scene_concepts.py` 自动选择。

### 2.1 `portal-cards` 信息传送门
- **语义**：消息 / 转发 / 聚合 / 入口 / 归集 / 变成 / 一键转 / 收件箱 → 产出
- **dark**：右侧一道发光传送门 / 漩涡，喷涌出漂浮的半透明 UI 卡片与看板瓷片冲向观者，
  每张卡片是玻璃质感、带抽象占位文字条；景深、轮廓光、暖色辉光，商业 3D 渲染。
- **light**：柔和光束 / 开口，纸页与干净 UI 卡片向外扇形飞出，日光、浅景深、产品摄影质感。
- **标杆**：微信群消息一键转 WorkBuddy（l10）。

### 2.2 `workflow-wheel` 自动化飞轮
- **语义**：自动 / 飞轮 / 流程 / 循环 / 闭环 / 流水线 / 编排 / pipeline / 批量 / 定时 / 无人值守 / 交给 / 委托 / 决策 / 授权 / 分工 / 协作 / 提效
- **dark**：右侧一个巨大发光圆环飞轮，环上是抽象步骤节点（无可读标签）与流向箭头，
  节点旁停靠漂浮卡片；影棚体积光，3D 信息图。
- **light**：柔和圆环工作流飞轮 + 圆角步骤节点 + 流向箭头，明亮极简影棚，3D 信息图。
- **标杆**：WorkBuddy+飞书公众号内容自动飞轮（l18）。

### 2.3 `desk-metaphor` 桌面实物隐喻
- **语义**：教程 / 系统 / 整理 / 收纳 / 笔记 / 文件 / 文件夹 / 归档 / 指南 / 实操 / 文档 / 备课 / 教案 / 教师 / 课件 / 讲义 / 教学 / 授课 / 课堂 / 作业 / 批改 / 学情 / 试卷 / 班主任 / 班务 / 班级 / 考勤 / 请假 / 家长 / 通知
- **dark**：右侧一张质感书桌，发光文件夹 / 收纳盒涌出漂浮纸页与卡片，影棚质感光、浅景深、商业静物。
- **light**：暖调书桌静物，打开的牛皮 / 珊瑚色文件夹涌出漂浮纸页，笔记本 + 小绿植，自然日光、纸张质感、产品摄影。
- **标杆**：WorkBuddy+ima 最系统教程（l17）。

### 2.4 `data-stream` 数据流汇聚
- **语义**：Token / 数据 / 亿 / 模型 / 生成 / 海量 / 参数 / 大模型 / 算力 / 语料 / 指标 / 图表
- **dark**：右侧一道巨量发光粒子数据流（token/像素）奔涌并凝聚成漂浮看板卡与幻灯片，
  暗调影棚 + 青 / 品红体积光，高科技商业 3D。
- **light**：柔和发光数据粒子与细线汇聚成干净看板卡片，明亮通透影棚，3D 渲染。
- **标杆**：1.9 亿 Token 做了个开源 PPT Skill（l8）。

### 2.5 `journey-panels` 内容画廊之旅
- **语义**：自由 / 解放 / 轻松 / 帮我 / 一键 / 神仙 / 告别 / 秒出 / 爆款 / 灵感 / 创意 / 成品
- **dark**：右侧一片开阔梦幻的漂浮内容面板 / 幻灯片画廊向戏剧性云层与光线深处延伸，
  一条光路通向它，史诗尺度，电影级 3D。
- **light**：明亮通透的内容面板 / 幻灯片画廊向柔云与日光延伸，丰盈与从容感，电影级渲染。
- **标杆**：WorkBuddy 里的神仙 skill 实现 PPT 自由（l14）。

### 2.6 `growth-steps` 阶梯增长
- **语义**：变现 / 副业 / 收入 / 赚钱 / 商业 / 营收 / 增长 / 涨粉 / 获客 / 定价 / 产品 / 转化率
- **dark**：右侧发光 3D 阶梯柱 + 叠币 / 柱状体 + 向上光箭头 + 漂浮指标卡，金融影棚光、金色辉光。
- **light**：柔和 3D 阶梯柱 + 轻叠币堆 + 向上箭头 + 指标卡，明亮影棚，商业插画质感。
- **标杆**：无（按「不限于参考图」扩展，覆盖变现 / 增长题材）。

### 2.7 `knowledge-graph` 知识图谱
- **语义**：知识 / 双链 / 认知 / 概念 / 学习 / 思维 / 体系 / 网络 / 图谱 / 连接 / 书 / 课程
- **dark**：右侧发光 3D 知识图谱——互联节点与弧线连成星座，漂浮卡片碎片，景深，3D 渲染。
- **light**：柔和 3D 星座节点 + 细弧连线 + 漂浮纸卡，明亮极简影棚，3D 渲染。
- **标杆**：无（扩展）。

### 2.8 `checklist-cards` 清单卡片
- **语义**：清单 / 步骤 / 避坑 / 模板 / SOP / 检查 / 自查 / 要点 / 坑 / 规范 / 模块 / 功能 / 工具箱 / 码上办 / 扫码 / 一站式 / 办事 / 版本更新
- **dark**：右侧一叠整齐扇开的清单卡与堆叠瓷片，带抽象勾选点与占位文字条，发光边缘，影棚 3D。
- **light**：整齐扇开的清单卡与纸张堆叠，抽象勾选点与占位文字条，明亮影棚，3D 渲染。
- **标杆**：无（扩展）。

### 2.9 `reform-cut` 改革减法
- **语义**：减法 / 做减法 / 精简 / 裁减 / 裁员 / 缩编 / 削减 / 改革 / 特权 / 公务员 / 大锅饭 / 铁饭碗 / 机构 / 编制 / 冗员 / 精兵简政 / 整顿 / 取缔 / 收紧 / 降本增效 / 瘦身 / 合并 / 重组 / 降薪 / 问责
- **dark**：右侧一把发光金色剪刀与切片刀刃切过一叠漂浮的公文卡片与文件夹，几张被裁掉的纸片飘散，背景隐约是发光世界地图 / 地球网格（暗示全球趋势）；暗调权威影棚光、暖金辉光，社论级 3D 渲染。
- **light**：明亮社论风——一把剪刀正在裁切整齐的漂浮纸质公文堆，裁片飘落，背景柔和地球 / 世界地图剪影；干净日光影棚，杂志级 3D 渲染。
- **标杆**：无（扩展，覆盖时政 / 改革 / 精简类题材）。

## 3. 语义选择规则

`scene_concepts.py` 对文案分层加权打分（同 `cover_motifs` 的 headline-first 读序）：

| 文案层 | 权重 |
|---|---|
| hero_lines 主标题 | 1.8 |
| eyebrow 眉题 | 1.2 |
| title_original 原标题 | 1.0 |
| topic 文章主旨 | 1.0 |
| subtitle 副标 | 0.9 |
| bottom_tags 标签 | 0.75 |

- 命中关键词得分 `len(kw)*2`，靠前（前 8 字）额外加分；关键词越长越优先。
- 取最高分原型为主场景；内容种子由文案 CRC32 推导，**同一篇文章可复现、不同文章各异**。
- 无命中时回退 `portal-cards`（通用「信息→产出」叙事，最百搭）。
- brief 可写 `"right_scene": "<id>"` 显式锁定，或 `"off"` 关闭场景化（回到风格默认背景）。

## 4. 提示词注入模板（`export_imagegen_prompt.py`）

输出结构：

```
<风格基底提示词（含色调）>
RIGHT-SIDE SCENE (theme-driven): <该原型的 dark/light 场景描述>
Theme context: <标题/topic —— 只做语义上下文，驱动场景，不渲染成文字>
Composition: keep the left 55-62% clean and uncluttered for headline typography.
Hard rules: no readable text, no letters, no Chinese characters, no logos,
no people, no face, no portrait, no watermark; abstract placeholder lines only.
Important: do not render the final title text; it will be added later with code.
```

## 5. 质检要点（针对场景）

- 右侧是**完整场景**，不是孤立小图标；与标题语义同频（一眼能联想到文章讲什么）。
- 左侧标题区仍干净，场景不侵入标题像素（逐像素/安全区检查照旧）。
- 场景内**无可读文字、无人脸**（放大右半边逐张确认）。
- 深色风格场景偏暗调电影感，浅色风格场景偏明亮摄影感，**与标题字色不冲突**。
