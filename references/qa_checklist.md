# 公众号封面质量检查表

发布前逐条检查。任意一项失败都要返工。

## 分享安全区（交付前必查，最易踩坑）

2.35:1 封面**不止被裁一次**：消息列表里是完整横幅，分享出去时只保留一个 1:1 方形（占画布宽度约 42.6%），其余左右两翼被切掉。

**本技能的交付/验收标准＝右 42.6% 切片（`share_side: right`，x 1350–2350）。** 默认版式「左标题 + 右主视觉」下，`check_cover` 导出的 `-share-1x1.png` 就是这块切片，验收看它。

- [ ] 已跑 `check_cover.py <图> --safe-zone --export-safe <前缀> --export-share <前缀>`（默认 `--share-side right`），确认打印出安全区像素范围
- [ ] 打开 `-share-1x1.png`：**右侧主题场景完整落在切片内、未被画布右缘裁切、未被标题/装饰压住**，且能独立成图。缺一角、被压住、只剩局部＝不合格，须重排背景或重出图
- [ ] 不套用「横幅好看就行」的豁免——横幅观感与切片观感**并列过检**，任一项不过即返工
- [ ] 标题块右边界按 `share_side` 收住：`right` 版式（默认）止于画布约 52%，`center` 版式止于约 28%；标题不得侵入右侧场景区
- [ ] 左翼（会被切掉的部分）只放眉标、副标、标签、账号名这类丢了也不影响的内容；核心语义靠横幅承载，场景靠切片承载
- [ ] 若用户明确要求场景居中，才切 `--share-side center`（x 675–1675）并按中央方形另行验收
- [ ] **没有把信息平均分到左右两侧的版式**——横版的「左右分栏」直觉在公众号封面上是陷阱，分享时正好把两侧切掉

⚠️ **实测反例（本包 ECONOMIST 样例）**：分享预览里三行标题左半部分被完全切掉，整句读不通。原因是标题块从 5.5% 左边距起排、按全宽铺开，越靠左的行被切得越狠。**标题块必须按 `share_side` 的 band 收住，不能按全宽铺开。**

## 尺寸与构图

- [ ] 画布比例为 2.35:1，推荐 2350x1000。
- [ ] 版面是**标题主导**：标题块从左侧留白起（5.5%，带左竖条的风格为 8.5%），**右边界按 `share_side` 收住**——`right` 版式（默认）止于画布约 52%，`center` 版式止于约 28%；右侧剩余空间留给主题场景，大字没有顶到边缘。
- [ ] 右侧是刻意留白或该风格自带的背景图样，**没有被用来塞人物/头像**。
- [ ] 四边保留安全边距：左右至少 80px，上下至少 60px。
- [ ] 25% 缩放查看时，主标题仍然一眼可读。

## 文案

- [ ] 主标题不超过 2 行，最多 3 行。
- [ ] 所有中文字符准确无误，无乱码、无错别字。
- [ ] 不使用 AI 图里生成的中文作为最终标题。
- [ ] 封面文案有判断、有具体信息：立场清楚、代价/收益具体，不喊空口号。
- [ ] 没有恐吓、绝对化承诺、虚构背书（见 SKILL.md「Cover copy rules」禁用清单）。
- [ ] 底部标签不超过 4 个。

## 无人物检查（硬性）

- [ ] 画面中**没有任何人物、人脸、头像、剪影或人手**，包括小头像卡片和背景里"顺便生成"的路人。
- [ ] 生成背景的提示词里保留了 `no people, no portrait`。
- [ ] 如果 imagegen 背景里出现了人，已作废重出，没有将就使用。

## 风格与轮换

- [ ] 已按星期自动选定风格（`style: auto`），或按用户要求显式指定；交付时说明用了哪套风格。
- [ ] **色调一致**：浅色风格（MONOCLE / NEW YORKER / KINFOLK）标题为深色字、无描边；深色风格（ECONOMIST / WIRED / HARVARD / 紫黑金）标题为亮色字 + 描边/发光。**不得出现浅底白字或深底黑字。**
- [ ] 生成背景用的提示词与该风格匹配（`export_imagegen_prompt.py` 导出的提示词），背景色调没有和文字色打架。
- [ ] 字体质感正确：衬线风格（ECONOMIST / NEW YORKER / KINFOLK / HARVARD）标题为宋体/衬线；无衬线风格（MONOCLE / WIRED / 紫黑金）为黑体。若系统缺衬线字体导致回退，需在交付说明中注明。
- [ ] 刊头（黑色条 / 斜体刊头）、竖条 + 竖排字、金色印章、侧带、顶部红条等装饰位置正确，未压住主标题。
- [ ] 主标题字数落在该风格推荐区间（见 `references/style_system.md` 轮换表）。
- [ ] 极大字距风格（KINFOLK）未因字距导致标题溢出标题区。

## 科技元素（仅深色科技风格）

- [ ] 背景暗，标题亮，对比强。
- [ ] 科技元素支持主题，而不是喧宾夺主。
- [ ] 没有虚假品牌 Logo、无意义水印、错乱 UI 文本。
- [ ] 整体像商业发布级封面，不像随手生成的 AI 图。

## 最终交付

- [ ] 输出 PNG 或高质量 JPG。
- [ ] 附带尺寸信息、所用风格（id + 名称 + 星期）。
- [ ] 若生成多个版本，推荐最佳版本并说明选择理由。
