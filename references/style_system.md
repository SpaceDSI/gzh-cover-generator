# 公众号封面视觉体系 · 14 套风格按星期轮换

本技能内置 14 套封面风格，**每个星期槽位 2 套（基准 + 候补），按 ISO 周奇偶自动交替**：偶数周出基准套，奇数周出候补套。同一星期相邻两周绝不重样，全部 14 套都参与轮换。

权威定义在 `scripts/style_presets.py`（`STYLE_PRESETS` / `WEEKDAY_ORDER` / `WEEKDAY_ALTERNATE`）。本文件解释每套风格的设计意图与落地要点。

- 轮换规则：**ISO 周序号奇偶**（`isocalendar()[1] % 2`）——偶数周整套出基准套、奇数周整套出候补套（`style_for_weekday()`）。不传日期时取该星期的基准套。
- **全部 14 套均参与轮换**，无「非轮换」遗留风格；用户显式点名任一风格可跳过轮换锁定。
- 「推荐字数」指**主标题（hero_lines 全部）的有效字数**（中文字 + 英文字母/数字，不含空格标点）。
- 字数偏少封面会显空，偏多字号会被自动压缩并挤占副标题，尽量落在区间内。

## 二、两种色调（tone）：决定整张封面的明暗逻辑

14 套风格分两类，渲染器据此切换文字色、描边与可读性遮罩：

| tone | 风格 | 背景 | 标题 | 说明 |
|------|------|------|------|------|
| `dark` | ECONOMIST / WIRED / HARVARD / DECO / TECH / CODEX / AGENT / CLEAN | 深色 | 亮色渐变字 + 描边 + 外发光 | 左侧会叠加暗色可读性遮罩 |
| `light` | MONOCLE / NEW YORKER / KINFOLK / HELVETIC / AEGEAN / BROADSHEET | 浅色纸感 | 深色实心字，无描边 | 不加暗色遮罩，保留纸面呼吸感 |

**关键约束**：浅色风格绝不能用白字（会与纸底糊在一起），深色风格绝不能用黑字。生成背景时务必使用该风格对应的 imagegen 提示词（见 `references/prompt_blueprints.md` 或 `python scripts/export_imagegen_prompt.py brief.json`），否则背景色调与文字色会打架。

## 三、14 套风格详规

### 1. `economist-crimson` · 财经权威（周一·基准）

- 底色：深红渐变 `#7E1414 → #600C0E → #3E0709`，轻纸纹 + 四周压暗。
- 刊头：**顶部通栏黑色刊头条**（高约 8.8% 画布），左侧一个红色方块 + 白色刊头文字（默认「智驭视界 · AI 实战周刊」），条下压一条红色细线。
- 标题：白色宋体/衬线大标题，营造权威财经周刊感；副标题徽章为**白底深红字**。
- 标签：白字、白色菱形符号。
- 适合：行业判断、趋势解读、数据复盘、商业分析。

### 2. `monocle-ivory` · 文化极简（周二·基准）

- 底色：米白 `#F3EEE4` 纯色纸感，极浅颗粒。
- 版式：**左侧一条黑色竖条**贴边，竖条右侧**竖排品牌小字**（默认「智驭视界」逐字下排）；顶部一条极细黑色横线。
- 标题：**无衬线粗黑大字**（黑体），近黑色；眉题前带黑色方块 + 下划线。
- 副标题徽章：黑底米白字。
- 适合：文化观察、生活方式、审美与方法论。

### 3. `newyorker-parchment` · 编辑厚重（周三·基准）

- 底色：羊皮纸 `#EFE6D4`，明显纸纹 + 轻压暗。
- 刊头：左上**斜体衬线刊头**（默认「智驭视界 · 深度手记」）+ 一条赭红下划线。
- 标题：**宋体/衬线大字**，近黑色，编辑厚重感。
- 副标题徽章：**赭红底米白字**。
- 适合：深度长文、人物特稿、叙事型内容。

### 4. `wired-black` · 未来张力（周四·基准）

- 底色：纯黑 `#09090B`，极淡技术网格 + 扫描线纹理。
- 顶部一条**亮红横条**（约 10px）。
- 标题：**超粗白头字**（无衬线），字距略收紧；眉题用黑底白字面板 + 红色方块。
- 副标题徽章：亮红底白字；标签用亮红菱形。
- 适合：前沿科技、AI 新物种、未来趋势、硬核解读。

### 5. `kinfolk-whitespace` · 东方留白（周五·基准）

- 底色：素白 `#FAF9F5`，极简，几乎无装饰，仅一条短细分隔线。
- 标题：**细衬线 + 极大字距**（约 0.20em），深灰；行距舒展，大量留白。
- 副标题徽章：素白底 + 细灰描边 + 深灰字。
- 适合：日常随笔、心得、慢思考、生活向内容。

### 6. `harvard-navy` · 学术克制（周六·基准）

- 标题：白色衬线大字，字色带一点暖金回光；副标题徽章为金色底深蓝字。
- 标签：白字 + 金色菱形。

### 11. `swiss-grid` · 瑞士网格（周一·候补，2026-10 新增）

- **核心概念**：国际主义平面风格（International Typographic Style / Swiss Design）。用一张「带模数网格的制图纸」承载标题——秩序、理性、克制，靠网格与规线而不是装饰取胜，与同日基准套 ECONOMIST 的深红权威感形成昼/夜两极。
- **版式结构**：顶部一条**信号红粗规线**（12px）；左上眉题前红色方块 + 红色下划线；标题下方一条**墨黑短规线**收束；底部标签行维持标准位置。标题区无刊头、无印章，起点最高（10.5%），大字距顶更近。
- **色彩体系**：纸白 `#F5F3EE → #E9E6DE` + 淡灰网格线 + 墨黑 `#101012` + **信号红 `#E32219`**（仅规线、菱形与点缀，绝不大面积铺红）。
- **字体风格**：**思源黑体 Bold**（`font: source-han-sans`），正字距 0，几何、干净、工程感。
- **关键视觉元素**：fallback 背景自带极淡灰色模数网格（118px 步进、30 透明度），如用 imagegen 背景请沿用提示词中的「faint modular grid」要求。
- **适用场景**：方法论、清单体干货、工具测评、理性分析类内容；周一开工日「冷静开局」的调性。

### 12. `aegean-postcard` · 爱琴海明信片（周二·候补，2026-10 新增）

- **核心概念**：一张被阳光晒褪的度假明信片。用「暖晒白纸面 + 爱琴海蓝标题 + 底部陶土色带」三段式营造旅行杂志般的松弛感，与同日基准套 MONOCLE 的黑白极简形成冷暖互补。
- **版式结构**：标题区标准起点；**底部一条横贯全宽的陶土橙色带**（自 85.5% 高度起，上沿一条晒白细边），**底部标签行整体压在色带上、改用浅色字**——这是该风格独有的「色带托标签」结构。
- **色彩体系**：晒白纸 `#FAF3E3 → #F0E6CE` + **爱琴海蓝 `#0E4A64`**（标题墨色）+ **陶土橙 `#E2725B`**（色带 / 徽章 / 菱形），点缀晒白细边。
- **字体风格**：**思源黑体 Bold**，字距 0.02em 略舒展，明快友好。
- **关键视觉元素**：色带是唯一的大色块；背景提示词要求蓝/陶土只以极柔和的抽象晕染或「海平线暗示」出现，保持上半部干净。
- **适用场景**：生活方式、旅行/效率工具、轻松经验分享、周中「喘口气」的内容。

### 13. `newsprint-extra` · 号外（周三·候补，2026-10 新增）

- **核心概念**：老报纸「EXTRA（号外）」版式——新闻纸、墨黑、朱红三色，紧急而克制。与同日基准套 NEW YORKER 同为纸感，但气质从「文学沙龙」切换为「印刷厂 urgency」。
- **版式结构**：顶部一条**墨黑粗规线**（12px）；其下**非斜体粗黑刊头**（默认「智驭视界 · 号外」）+ **朱红下划线**；标题区起自 21.5%；**三条竖向报纸栏线**（40%–87% 高度，淡墨 52 透明度）从标题文字底下穿过——**字压栏线**是号外最有辨识度的 authentic 细节。
- **色彩体系**：新闻纸白 `#F7F5F0 → #EDEAE3` + 墨黑 `#0A0A0A` + **朱红 `#C8102E`**（刊头下划线 / 菱形 / 徽章），全封面只有这三色。
- **字体风格**：**思源黑体 Bold**，字距 -0.01em 微收紧，标题更挤更重。
- **关键视觉元素**：栏线 + 粗黑规线 + 纸纹颗粒；副标题徽章为**朱红底米白字**。
- **适用场景**：突发热点跟进、重要发布、数据/事件速报，「今天有大事」的调性。

### 14. `deco-noir` · 盖茨比之夜（周四·候补，2026-10 新增）

- **核心概念**：1920 年代 Art Deco 装饰艺术 × 午夜奢华。用「金色刊头带 + 金线装饰框 + 四角扇形」把整张封面装裱成一支老牌晚宴请柬，与同日基准套 WIRED 的纯黑未来感形成一古典一未来的对撞。
- **版式结构**：顶部**香槟金通栏刊头带**（深绿字，默认「智驭视界 · 午夜特刊」）；其下**金色双线装饰框**（外框 3px + 内框 2px，上沿内缩至 12.5% 让开刊头带）围住整个标题区，**四角 6 道放射扇形**（sunburst fan）是点睛装饰；标题、徽章、标签全部收在框内。
- **色彩体系**：午夜孔雀绿渐变 `#103E30 → #0A2A21 → #051A14` + **香槟金 `#C9A227`** + 象牙白 `#F5EFE0`，深色 tone（标题走金/象牙渐变 + 描边 + 外发光）。
- **字体风格**：**思源黑体 Bold**，**宽字距 0.10em**——Deco 的仪式感一半来自字距。
- **关键视觉元素**：双线框 + 扇形角 + 金刊头带三件套；背景提示词要求对称的 deco 细线、放射线与阶梯 chevron 纹样。
- **适用场景**：年度总结、重磅复盘、晚会/活动招募、高端品牌向内容；「今晚有点隆重」的调性。

## 四、轮换机制（ISO 周奇偶交替）

每个星期槽位固定配对 2 套：**基准套（`WEEKDAY_ORDER`，ISO 偶数周）+ 候补套（`WEEKDAY_ALTERNATE`，ISO 奇数周）**。`style_for_weekday(weekday, date)` 按 `date.isocalendar()[1] % 2` 取对应一套；同一自然周内 7 天各自恒定，下一周整体切换到另一套——相邻两周同一星期绝不重样，14 套全部参与轮换。

配对一览（基准 ↔ 候补）：

- 一：`economist-crimson` ↔ `swiss-grid`
- 二：`monocle-ivory` ↔ `aegean-postcard`
- 三：`newyorker-parchment` ↔ `newsprint-extra`
- 四：`wired-black` ↔ `deco-noir`
- 五：`kinfolk-whitespace` ↔ `clean-business-tech`
- 六：`harvard-navy` ↔ `agent-cyber`
- 日：`tech-purple-gold` ↔ `codex-blue-gold`

**全部 14 套均参与轮换**；用户显式点名任一风格可跳过轮换锁定。

别名（可直接传）：新增 4 套可用 `swiss` / `helvetic` / `瑞士网格` / `aegean` / `爱琴海` / `明信片` / `extra` / `broadsheet` / `号外` / `新闻纸` / `deco` / `盖茨比` / `装饰艺术`；原有别名 `obsidian-purple-gold` / `purple-gold` / `紫黑金科技风`、`economist`、`财经权威`、`monocle`、`文化极简`、`new-yorker`、`编辑厚重`、`wired`、`未来张力`、`kinfolk`、`东方留白`、`harvard`、`学术克制`、`codex`、`黑蓝金科技风`、`agent`、`智能体蓝青风`、`clean`、`极简商务科技风` 同样可用。

## 五、版式比例（所有风格共用）

画布 2.35:1，推荐 2350×1000。

- 标题块起点：左边距 5.5%（带左侧竖排条的风格为 8.5%）。标题块自上而下依次是眉题、主标题（1–3 行）、副标题徽章。
- 标题块可用宽度：右边界止于画布 80%（带竖排条的风格 78%），即**右侧至少留 20% 留白**，绝不让大字顶到画布边缘。
- 右 80–100%：留白区，或由该风格自带的背景图样（霓虹/图样/纸面肌理）收尾。**不放人物、不放头像。**
- 下方约 87.5%：底部标签行（`aegean-postcard` 的标签行压在陶土色带上，颜色由该风格自带）。
- 四边安全边距：左右 ≥ 80px，上下 ≥ 60px；`deco-noir` 的金线框内缩约 2.8% 画布宽，标题、徽章、标签均收在框内不越线。

**主标题字号是所有风格共用的品牌常量**（上限 206px，见 `render_wechat_cover.py` 的 `HEADLINE_CEILING`），**不随风格变化**——风格差异只来自装饰件、配色与字体，不来自字的大小。两处刻意的例外：

- 带刊头（ECONOMIST / NEW YORKER / BROADSHEET / DECO）或印章（HARVARD）的风格，标题区整体下移，纵向预算变紧，字号相应略小；
- 带正向字距的风格（MONOCLE 0.02em / AEGEAN 0.02em / KINFOLK 0.20em / DECO 0.10em）字距占宽，可用宽度更窄，字号相应略小；BROADSHEET / WIRED / TECH 用 -0.01em 负字距，因此能塞下更大的字。

这两项差异是设计结果，不是渲染故障。描边不计入字号高度预算（描边向外溢出，由行距吸收），否则所有深色风格都会比同款浅色风格小一档。

纵向预算（眉题 + 主标题 + 徽章必须全部排在标签行之上）由渲染器自动计算；预算不足时优先缩小主标题字号，绝不重叠。

## 六、字体与回退

- **思源黑体 Bold（source-han-sans 家族）**：2026-10 新增 4 套（swiss-grid / aegean-postcard / newsprint-extra / deco-noir）的封面文字统一字体。候选链首选 Windows `NotoSansSC-VF.ttf`（即可变字重版思源黑体，渲染器自动挑 Bold 实例），其后依次是 `SourceHanSansSC-Bold/Regular.otf`（含用户级字体目录）、Linux Noto Sans CJK；思源系列全部缺失时回退到通用无衬线链（微软雅黑等），**不会崩**。想给其余风格也换思源黑体，只需在 `style_presets.py` 对应 preset 加 `"font": "source-han-sans"`。
- 无衬线（默认）：Microsoft YaHei Bold / Noto Sans SC / 黑体 / PingFang。
- 衬线（宋体）：华文中宋 `STZHONGS.TTF` / Noto Serif SC / 华文宋体 `STSONG.TTF` / 宋体 `simsun.ttc`。
- 渲染器按风格自动选字体，并在候选列表中逐级回退；若系统无 CJK 衬线字体，会回退到无衬线（此时风格仍有色彩/版式差异，但宋体质感会减弱）。

## 六之二、右侧组合构图（right_motif）

标题块止于画布 80%（竖排条风格 78%），右侧余下的保留区由 `scripts/cover_motifs.py` 生成一组**语义驱动的组合图形**，解决「左边重、右边空」与「每篇右半边都一样」两个问题。

- **组合结构**：主图标（区高 50–60%）+ 次图标（26–36%）+ 2 组点缀，共 9 族图标 × 5 类点缀 × 4 种版式（`stack` 上下分层 / `stagger` 错位对角 / `centerpiece` 大图居中 / `ladder` 阶梯三段）。
- **语义提取**：主标题 1.8 → 眉题 1.2 → 原标题 1.0 → 副标 0.9 → 标签 0.75 分层打分；关键词越长、越靠前得分越高。次图标取第二高分族，无第二命中时用语义相邻表补位（growth→data / knowledge→quote / checklist→gear / pulse→waves / quote→knowledge 等）。
- **确定性**：构图种子 = 文案归一化后的 CRC32（并入 brief `seed`）。同一篇 ⇢ 同一封面（逐次可复现）；不同篇 ⇢ 不同主次/版式/点缀/尺寸配比；`seed` 不同 = 同一篇的另一种构图。
- **绘制区**：`x` 起于标题右边界 +1.4% 画布宽，止于 95.5%（让开装饰艺术金框与右安全距）；`y` 为 13.5%–79%（让开刊头带与底部标签行）。**最后一层按矩形硬裁剪**，图元任何越界都会被裁掉，标题区像素零改动。
- **配色与密度**：只取该风格自身的 `accent` / `ink`（深色风格线更亮、浅色更沉），透明度低、无文字（卡片为骨架线），画在文字层之下。
- **窄画布自动隐藏**：宽度 < 1400 或高度 < 380、或保留区 < 150×180 时整组跳过，等效窄屏收起，不会溢出或横向滚动。
- **关闭/锁定**：brief 写 `"right_motif": "off"` 关闭；写具体图标 id 锁定主图标；构建时用 `--motif`。
- 渲染日志会打印构图签名（如 `[motif=agent+data/stack]`），便于复盘每篇文章实际用了什么组合。

## 七、禁用事项

- 浅色风格不要用白字、深色风格不要用黑字（`aegean-postcard` 的底部标签是唯一例外——它们压在陶土色带上）。
- 右侧主题图形不要用真实文字、不要放人物/头像，也不要画到标题右边界以内。
- 不要让封面出现 5 个以上视觉中心。
- 不要把正文塞进封面。
- 不要在 imagegen 里要求生成准确中文（中文一律用代码绘制）。
- 不要放任何人物/头像/人脸（封面是纯文字主导的杂志风）。
- 不要让副标题徽章压住主标题（渲染器已做纵向预算，人工调整字号时仍需检查）。
- 不要把 imagegen 背景铺到 `deco-noir` 的金线框上不加暗遮罩——深色风格请沿用其专属提示词。
